# OFOQ | أفق — النسخة الاحترافية

## ما الجديد؟
- تحسين الخطوط للغتين: Cairo للنص العربي وInter للنص الإنجليزي، مع أوزان إضافية.
- إضافة أيقونات PNG بأحجام 192×192 و512×512 وأيقونة Apple Touch بحجم 180×180.
- إضافة `site.webmanifest` لدعم إضافة الموقع إلى الشاشة الرئيسية على الأجهزة والمتصفحات المدعومة.
- إضافة إعدادات أيقونة التطبيق ولون المتصفح إلى جميع الصفحات.

## النشر على Cloudflare Pages
ارفع **كل محتويات هذا المجلد** إلى جذر المشروع، وتأكد من وجود `index.html` في الجذر مع `site.webmanifest` ومجلد `icons` و`favicon.svg` وملفات CSS وJavaScript وبقية الصفحات.

## تثبيت الموقع على الجهاز
- Android/Chrome: افتح الموقع المنشور، ثم قائمة المتصفح واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن ظهر الخيار.
- iPhone/Safari: افتح الموقع في Safari، ثم «مشاركة» وبعدها «إضافة إلى الشاشة الرئيسية».

يجب أن يكون الموقع منشورًا عبر HTTPS حتى تعمل ميزات التثبيت بصورة سليمة. قد تختلف الخيارات حسب الجهاز والمتصفح. الخطوط تُحمّل من Google Fonts وتتطلب اتصالًا بالإنترنت، مع خطوط بديلة عند تعذر التحميل.
