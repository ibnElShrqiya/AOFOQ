# OFOQ | أُفُق
Multi-page static site (HTML/CSS/vanilla JS). Run locally: `python3 -m http.server` in this folder, open http://localhost:8000.
All paths are relative, so it also works from a sub-folder (GitHub Pages) or a domain root (Cloudflare Pages).

## Edit
Pages are generated by `build.py` (services, projects, texts, bilingual as `{عربي|English}`). Edit it, then run `python3 build.py`. The generated HTML is committed, so deployment needs no build step. Header/footer are static in every page (no blank pages if JS fails).
- Add a project: add a row to `PR` in `build.py`; verified features/links/screenshots go in its detail page (currently marked "not documented yet").
- Before launch: set `DOMAIN` in `build.py` (sitemap.xml) and rebuild.

## Fonts
Stacks name IBM Plex Sans Arabic, Inter, Space Grotesk, JetBrains Mono with system fallbacks. None are bundled or loaded remotely. To use them, add licensed WOFF2 files to `assets/fonts/` and `@font-face` rules in `css/site.css`.

## Works now
AR/EN on every page (saved in localStorage), RTL/LTR, mobile menu, filters, reveal/tilt/terminal/grid animations (reduced-motion respected), floating WhatsApp button, validated request form.

## Needs setup
